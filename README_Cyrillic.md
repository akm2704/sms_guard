# SMS Guard: исправление ложных классификаций кириллицы в учебном прототипе

## Почему
Английская LogisticRegression обучена на UCI SMS Spam Collection. Её оценки для кириллических сообщений не валидированы. Пример обычного русского SMS с вероятностью спама 88.11% — следствие применения модели вне области обучения, а не доказательство спама.

**Важно по ТЗ:** `data/raw/custom_ru_kk.csv` — тестовый набор для проверки многоязычности, не использовать его для дообучения или оптимизации порога. Он также содержит метки `AI_draft_requires_review`, которые требуют ручной проверки перед независимой оценкой.

## Что делает патч
- Английские SMS: прежняя LogisticRegression, прежние вероятности.
- SMS, содержащие кириллицу (русский и казахский): прозрачный словарь `ml/rules.py` + наличие URL, денежных сумм, телефона. **Без ML-вероятности**, без утверждения о безопасности.
- Явные признаки выводятся списком; отсутствие признаков означает лишь отсутствие известных срабатываний.
- Обе ветки продолжают работать без чтения/записи SMS в историю.

## Установка
1. Сделайте копии файлов `apps/analysis/views.py`, `templates/check_sms.html`.
2. Скопируйте папки `ml/`, `apps/`, `templates/`, `tests/` из патча в корень проекта `sms_guard`. Разрешите замену **только** `apps/analysis/views.py` и `templates/check_sms.html`. Уже внесённая правка `unlocalize` сохранена.
3. В терминале VS Code запустите:

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe manage.py runserver
```

4. В браузере откройте `http://127.0.0.1:8000/check/sms/`.

## Демонстрация
- `Напоминаю: Ваша встреча назначена на завтра в 14:00.` → «Явных тревожных признаков по текущему словарю не найдено» (не «безопасно» и не числовой ML-процент).
- `Срочно переведите 5000 ₸ и сообщите код подтверждения!` → «Найдены признаки, требующие внимания», выводятся соответствующие группы.
- `Сәлем! Ертең сағат 15:00-де кездесейік.` → словарный анализ без вероятности.
- `URGENT! Claim your prize.` → прежняя английская ML-модель и её вероятность.

## Как получить настоящую ML-поддержку ru/kk
Нужен **отдельный размеченный набор для обучения** с реальными вариациями безопасных и мошеннических сообщений (с согласиями или полностью искусственными). После проверки разметки — раздельные train/val/test по языкам, дообучение/новая модель и оценка на **нетронутом** `custom_ru_kk.csv`. Только после этого можно показывать в интерфейсе подтверждённую ML-оценку ru/kk. Не обучайте модель на собственном тестовом наборе.
