# Паспорт набора данных SMS Spam Collection

## 1. Общая информация

**Название проекта:** Интеллектуальная система обнаружения мошеннических SMS-сообщений и подозрительных ссылок (SMS Guard).

**Название датасета:** SMS Spam Collection.

**Источник:** UCI Machine Learning Repository.

**Ссылка:** https://archive.ics.uci.edu/dataset/228/sms+spam+collection

**Авторы:** Tiago Almeida, José Hidalgo.

**Лицензия:** Creative Commons Attribution 4.0 International (CC BY 4.0).

**Дата загрузки:** 31.10.2026 (уточнить по фактической дате скачивания).

**Язык сообщений:** английский.

**Назначение:** обучение модели машинного обучения для автоматической классификации SMS-сообщений.

## 2. Структура набора данных

Исходный набор SMS Spam Collection содержит 5574 текстовых сообщения, размеченных по двум категориям: ham и spam.

После загрузки данные были преобразованы в таблицу со следующими столбцами:

| Столбец | Тип данных | Назначение                         |
| ------- | ---------- | ---------------------------------- |
| id      | int64      | Уникальный идентификатор сообщения |
| text    | object     | Исходный текст SMS                 |
| label   | int64      | Категория сообщения                |

Целевая переменная `label` принимает два значения:

* 0 — обычное сообщение (ham);
* 1 — спам-сообщение (spam).

## 3. Распределение классов

После загрузки датасета получены следующие результаты:

| Категория   | Количество | Процент |
| ----------- | ---------: | ------: |
| Обычные SMS |       4827 |  86,60% |
| Спам-SMS    |        747 |  13,40% |
| Всего       |       5574 |    100% |

Результаты показывают наличие дисбаланса классов.

Количество обычных сообщений значительно превышает количество спам-сообщений.

При дальнейшем обучении моделей необходимо учитывать данную особенность с помощью стратифицированного разделения данных, подходящих алгоритмов и метрик качества.

## 4. Загрузка и обработка

Для загрузки данных разработан Python-скрипт `ml/data/load_sms.py`.

В процессе выполнения были реализованы следующие операции:

1. Чтение исходного файла SMS Spam Collection.
2. Проверка кодировки исходных данных.
3. Загрузка информации с использованием библиотеки Pandas.
4. Преобразование текстовых категорий ham и spam в числовые значения 0 и 1.
5. Создание уникальных идентификаторов сообщений.
6. Определение количества записей и типов столбцов.
7. Анализ распределения классов.
8. Сохранение данных в CSV-файл.

Результат сохранён:

`data/processed/sms_raw.csv`

Файл использует кодировку UTF-8.

## 5. Ограничения набора данных

Основным ограничением является то, что SMS Spam Collection содержит сообщения на английском языке.

Это означает, что модель, обученная исключительно на данном наборе, не сможет гарантировать аналогичное качество классификации сообщений на русском и казахском языках.

Кроме того, категория spam не полностью соответствует понятию мошенничества. В наборе присутствуют рекламные и нежелательные сообщения, которые не обязательно связаны с фишингом или финансовыми преступлениями.

Для дополнительного тестирования системы планируется использовать отдельный набор искусственных сообщений:

* 100 сообщений на русском языке;
* 50 сообщений на казахском языке.

Данный набор будет использоваться для оценки работы системы на других языках и не будет включён в обучающую выборку.

## 6. Вывод

В ходе выполнения задания был успешно загружен набор данных SMS Spam Collection.

Получены 5574 сообщения, из которых 4827 относятся к категории обычных сообщений, а 747 — к категории спама.

Данные преобразованы в единую структуру с числовой целевой переменной и сохранены в формате CSV.

Полученный набор будет использоваться для предварительной обработки текста, извлечения признаков TF-IDF и последующего обучения моделей машинного обучения.
