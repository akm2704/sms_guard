# SMS Guard — проверка проекта и продолжение задания №6

В ZIP находятся **только добавляемые/исправленные файлы**, а не весь проект. Архив не содержит `.env`, базы пользователей, данных или моделей.

## Установка

1. Перед копированием сохраните резервную копию `ml/data/load_sms.py` и `notebooks/02_sms_features.ipynb`.
2. Скопируйте содержимое папки `ml/`, `scripts/` и `tests/` из ZIP в одноимённые папки существующего проекта, разрешив замену `ml/data/load_sms.py`.
3. Скопируйте `notebooks/02_sms_features_READY.ipynb` в `notebooks/`. Он содержит предыдущие четыре шага и продолжение с TF-IDF. Выполните все ячейки и по окончании сохраните как `02_sms_features.ipynb`.
4. Из корня проекта выполните:

```powershell
.\.venv\Scripts\python.exe ml\data\load_sms.py
.\.venv\Scripts\python.exe scripts\run_task06.py
.\.venv\Scripts\python.exe -m pytest -q
```

**Исправление задания №3:** в `load_sms.py` убран преждевременный `return` из `main()`. Теперь скрипт снова показывает статистику и сохраняет файл. При сохранении столбцы будут в порядке `id, text, label`.

**Задание №6:** ожидаемый вывод размерностей на предоставленном датасете (при scikit-learn 1.8.0) был `Train: (3572, 29651)`, `Validation: (765, 29651)`, `Test: (766, 29651)`. При другой версии число столбцов может отличаться; оно должно совпадать между тремя наборами.

`rules.py` содержит **предварительный** словарь групп для ручного признака в задании №6; он не претендует на полное выполнение задания №12.

Не используйте `fit` или `fit_transform` на `validation` и `test`. Для задания №7 обучайте классификатор только на `train`, проверяйте качество на `validation`.
